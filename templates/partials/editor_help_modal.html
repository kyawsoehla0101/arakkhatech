{# Shared keyboard-shortcut help modal for the Markdown editor. #}

Keyboard Shortcuts

Ctrl/Cmd + B Bold (အနက်)
Ctrl/Cmd + I Italic (စောင်း)
Ctrl/Cmd + K Link (ချိတ်ဆက်)
Ctrl/Cmd + S Save (သိမ်းရန်)
Ctrl/Cmd + Z Undo (ပြန်ဖျက်)
Ctrl/Cmd + Y Redo (ပြန်လုပ်)
Tab Indent (အတွင်းသို့ရွှေ့)
Shift + Tab Outdent (အပြင်သို့ရွှေ့)
Ctrl/Cmd + 1 … 6 Heading H1-H6 (ခေါင်းစဉ်အဆင့်)
Ctrl/Cmd + 0 Normal text (ခေါင်းစဉ် ဖြုတ်)
Ctrl/Cmd + Shift + C Code + Language Picker (ကိုဒ်ဘာသာစကား ရွေး)

နည်းပညာစာ အတွက် အထူး: Code ခလုတ်ဖြင့် ဘာသာစကား ရွေးပြီး ကိုဒ်အကွက် ထည့်နိုင်သည်။ TOC ခလုတ်က [TOC] မာတိကာ ထည့်ပေးသည်။ Table ခလုတ်က ကော်လံ/အတန်း/ချိန်ညှိမှု ရွေးနိုင်သော ဇယားဖန်တီးစက် ဖွင့်ပေးသည်။

စာရေးနေစဉ် အလိုအလျောက် Draft အလုပ်လုပ်ပါသည်။ သတိမထားမိဘဲ စာမျက်နှာပိတ်သွားပါက ပြန်ဖွင့်ချိန်တွင် Draft ကို ပြန်လည်ရယူနိုင်ပါသည်။
